## キービジュアルの数理モデル

[Generative Flower — Order × Chaos](https://github.com/York-14/Generative-flower-Order-Chaos) の
対称カオス写像は、原点まわりに *n* 回回転対称な **放射状** の模様を描きます。
横から見ると平たい円盤にしかならず「下から上へ成長する木」は表せないため、
成長の骨格は新しく組み直し、元のモデルからは次の 3 つを引き継いでいます。

| 引き継いだもの | 木での役割 |
|---|---|
| 対称カオス写像 `z ← (λ + α|z|² + β Re zⁿ) z + γ z̄ⁿ⁻¹` | ゆらぎ ξ ∈ [−1, 1] の源（乱数の代わりに決定論的カオスを使う） |
| `Beauty = Order × Complexity × Contrast` | 候補 6 本の木から最も釣り合った 1 本を選ぶ |
| 密度ヒストグラム + 対数トーンマップ | 点を加算して針葉の質感を描く |

### Order（秩序）

- 節間：`y_k = y0 + (1 − y0)(1 − q^k)/(1 − q^K)`（q = 0.955、梢に向かって詰まる）
- 葉序：段ごとに黄金角 137.5° 回転、1 段に 5 本（回転対称の次数 n に相当）
- 円錐：`L_k = L0 (1 − h_k)^0.92`
- 枝の形：`v(s) = L (s·tan a − g s² + u s³)`（仰角 a・自重 g・先端の反り u）
- 自己相似：小枝は親枝の比で短くなる

### Chaos（混沌）

`c ∈ [0, 1]`（画面の Order ↔ Chaos スライダー）でゆらぎ ξ の振れ幅を決め、
節間・方位・枝長・仰角・枝の曲がり・枝数・枝の欠落に注入します。針葉の散らばりも同じ写像の軌道です。

### Growth（成長）

成長前線が `t(y) = T·y^1.05` で根元から梢へ上がり、通過した段から枝が伸び始めます。
枝の伸長時間は `√(L/L0)` に比例するので、下の枝ほど長く伸び続け、その時間差が円錐になります。

### Beauty（評価）

| 項 | 測るもの | 好む値 |
|---|---|---|
| O | 左右の鏡映対称（シルエットの IoU） | 0.7 付近（完全対称は退屈） |
| C | ボックス次元 | 1.7 付近（線と面の中庸） |
| K | 輪郭内の余白 | 0.2 付近 |
