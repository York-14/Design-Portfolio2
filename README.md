## キービジュアルの数理モデル

[Generative Flower — Order × Chaos](https://github.com/York-14/Generative-flower-Order-Chaos) の
対称カオス写像は、原点まわりに *n* 回回転対称な **放射状** の模様を描きます。
横から見ると平たい円盤にしかならず「下から上へ成長する木」は表せないため、
成長の骨格は新しく組み直し、元のモデルからは次の 3 つを引き継いでいます。

| 引き継いだもの | 木での役割 |
|---|---|
| 対称カオス写像 `z ← (λ + α|z|² + β Re zⁿ) z + γ z̄ⁿ⁻¹` | ゆらぎ ξ ∈ [−1, 1] の源（乱数の代わりに決定論的カオスを使う） |
| `Beauty = Order × Complexity × Contrast` | 候補 6 本の木から最も釣り合った 1 本を選ぶ |
| 密度ヒストグラム + 対数トーンマップ | 点を加算して針葉の質感を描く |

### Seed → Genome → Leaves

木が生まれるたび（初回・「もう一度育てる」・散って再び育つとき）に 32 bit の seed を生成して画面に表示します。
`?seed=0x7CEE6D8D` のように URL に付けると、その木をそのまま再現できます（画面の seed はそのリンク）。

seed は splitmix32 で展開され、次の「遺伝子」を決めます。カオス写像の初期値 `z0` も seed から決まります。

| 遺伝子 | 範囲 |
|---|---|
| 1 段の枝数 n | 4〜7 |
| 段数 K | 22〜30 |
| 細さ L0 | 0.20〜0.25 |
| 葉序 p/q | 2/5, 3/8, 5/13, 8/21, 13/34（Fibonacci 比 → 黄金角に収束） |
| 葉角 α0 | 40〜65° |
| 葉の長さ λ / 間隔 Δ | λ = 0.011〜0.017、Δ = λ·(0.04〜0.065) |

葉（針葉）は数理モデルで置きます。

- 本数：`N = Σ ⌊ℓ·ρ / Δ⌋`（各小枝の長さ ℓ と密度 ρ を間隔 Δ で割る）。画面に「葉 95,728 本」のように表示
- 向き：`d_k = cos α_k·T + sin α_k·(cos ψ_k·N1 + sin ψ_k·N2)` に上向きの癖を加える。`ψ_k = 2π·k·p/q + c·ξ`、`α_k = α0 + 0.35·c·ξ`（T は小枝の向き、N1・N2 はその法線）
- 各葉は数点の線として描き、秩序の姿（c = 0）と混沌の姿（c = 1）の 2 つの座標を持つ

Beauty で候補を選ぶ場合も、候補の seed は元の seed からハッシュで決まり、表示されるのは実際に育った木の seed です。

### Order（秩序）

- 節間：`y_k = y0 + (1 − y0)(1 − q^k)/(1 − q^K)`（q = 0.955、梢に向かって詰まる）
- 葉序：段ごとに黄金角 137.5° 回転、1 段に 5 本（回転対称の次数 n に相当）
- 円錐：`L_k = L0 (1 − h_k)^0.92`
- 枝の形：`v(s) = L (s·tan a − g s² + u s³)`（仰角 a・自重 g・先端の反り u）
- 自己相似：小枝は親枝の比で短くなる

### Chaos（混沌）

`c ∈ [0, 1]`（画面の Order ↔ Chaos スライダー）でゆらぎ ξ の振れ幅を決め、
節間・方位・枝長・仰角・枝の曲がり・枝数・枝の欠落に注入します。針葉の散らばりも同じ写像の軌道です。

### Growth（成長）

成長前線が `t(y) = T·y^1.05` で根元から梢へ上がり、通過した段から枝が伸び始めます。
枝の伸長時間は `√(L/L0)` に比例するので、下の枝ほど長く伸び続け、その時間差が円錐になります。

### Rhythm（緊張と緩和）

成長し終えた木は、呼吸の相のあいだ鼓動に合わせて Order ↔ Chaos を行き来します。

- テンポ：`BPM(t) = 100 − 20 cos(2πt / 24)`（24 秒周期で 80 → 120 → 80 BPM）。拍の位相はその積分 `φ(t) = [100t − 20·(24/2π)·sin(2πt/24)] / 60`
- 緊張：`τ = (1 − cos(2πt / 24)) / 2`（速いほど緊張）
- 混沌度：`c(t) = c0 + 0.5(τ − 0.4) + 0.16·beat·(0.35 + 0.65τ)`（`c0` はスライダー。拍は一瞬で立ち上がりゆっくり戻る心拍型）
- 実装：構造（枝の本数）は `c0` で固定し、各点に「秩序の姿（c = 0）」と「混沌の姿（c = 1）」の 2 つの画面座標を持たせて毎フレーム補間。`C²·0.35` を超えた枝は溶けるように消える
- 画面外・非表示タブでは停止。「止める」ボタンで静止、`prefers-reduced-motion` では静止画

### Life cycle（育つ → 枯れる → 散る → 再び育つ）

一本ずつが「生命の時計」`L` を持ち、鼓動に合わせた可変の速さで進みます（変速）。

```
dL/dt = (BPM / 100)^1.6 · (1 + 0.55·beat)
```

| 相 | 長さ（L の秒） | 内容 |
|---|---|---|
| 育つ | 約 6.5 | 成長前線が根元から梢へ |
| 呼吸 | 16（遠景は 10〜22） | 上の Rhythm で Order ↔ Chaos |
| 枯れる | 5.5 | 枯れる順番 `Q`（梢・枝先が先、幹が最後）に従い緑が抜けて乾いた色の層へ。自重で垂れ、混沌度は 0.85 へ |
| 散る | 5.5 | 枯れた順に枝を離れる。半分は宙で風化、残りは風に揺れて落ち、地面に積もって消える。幹は最後に消える |
| 眠る | 1.6 | 何もない。主木はこの間に新しい seed を Beauty で選び直し、点群を数ミリ秒ずつ焼いておく |

### Beauty（評価）

| 項 | 測るもの | 好む値 |
|---|---|---|
| O | 左右の鏡映対称（シルエットの IoU） | 0.7 付近（完全対称は退屈） |
| C | ボックス次元 | 1.7 付近（線と面の中庸） |
| K | 輪郭内の余白 | 0.2 付近 |
