01

Concept

美しさは、完全な秩序にも、純粋な混沌にもない。
そのあいだに、凛とした一本が立つ。

OOrder — 秩序

黄金角 137.5° で回る輪生枝、円錐の包絡線、梢に向かって等比で詰まる節間。針葉樹が何千万年もかけて選んできた「規則」をそのまま式にしています。

CChaos — 混沌

枝の角度・長さ・曲がり、針葉の散らばりには、対称カオス写像の軌道をゆらぎとして注ぎます。乱数ではなく決定論的なカオス。初期値がわずかに違えば、まったく別の木になります。

BBeauty — 評価

候補の木をいくつも育て、Order × Complexity × Contrast の評価関数でいちばん釣り合いの取れた一本を選びます。派手すぎず、質素すぎない「中庸」を数値で探す試みです。

03

Model

花の数理モデルを、木の数理モデルへ。

Generative Flower で使った対称カオス写像は、原点まわりの n 回回転対称を持つ放射状の模様を描きます。横から見ると平たい円盤にしかならず、「下から上へ育つ」形は表せません。そこで成長の骨格は新しく組み直し、写像はゆらぎの源として、評価関数は木の選別として受け継ぎました。

Chaos source

zt+1 = (λ + α|z|² + β Re zn) z + γ z̄ n−1

Generative Flower の写像そのもの（λ = −2.34, α = 2, β = 0.2, γ = 0.1, n = 5）。軌道 zt / R を [−1, 1] のゆらぎ ξ として取り出します。

Order — 節間と葉序

yk = y0 + (1 − y0) · (1 − qk) / (1 − qK) + c·ξ,   θk = k · 137.5° + c·ξ

段の間隔は梢に向かって公比 q = 0.955 で詰まり、段ごとに黄金角だけ回ります。c は Order ↔ Chaos のバランス。

Order — 円錐と枝の形

Lk = L0 (1 − hk)0.92 (1 + c·ξ),   v(s) = L (s·tan a − g s² + u s³)

枝の長さは円錐の包絡線に従い、枝は仰角 a で出て自重 g で垂れ、先端 u でわずかに反り上がります。小枝は親枝の比で短くなる自己相似。

Growth

t(y) = T · y1.05,   τk ∝ √(Lk / L0)

成長前線が根元から梢へ上がり、通過した段から枝が伸び始めます。下の枝ほど長く伸び続けるので、時間差がそのまま円錐の形になります。

Beauty

B = O · C · K

O：左右の鏡映の度合い（完全対称は退屈なので 0.7 付近が最良）。C：ボックス次元（線と面の中庸 ≈ 1.7）。K：輪郭内の余白。候補 6 本から B 最大の木を描きます。
